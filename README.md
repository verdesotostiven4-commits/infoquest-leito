# InfoQuest Leito · Academia de Aventuras

Juego educativo web para repasar Informática, Ciencias Naturales y Estudios Sociales de 5.º EGB.

## Estudios Sociales

La aventura de Estudios Sociales está basada en el libro, cuadernillo y cuaderno de Leo e incluye:

- Origen y evolución del Homo sapiens.
- Teorías y rutas del poblamiento de América.
- Vida nómada, actividades y organización de los primeros pobladores.
- Herramientas y materiales naturales.
- Regiones naturales del Ecuador y sus nombres alternativos.
- Mapa y límites del Ecuador.

Cada mundo sigue la ruta **mini clase → videojuego → práctica → reparación de errores**. Los minijuegos incluyen línea del tiempo, rutas sobre mapas, supervivencia nómada, memoria de herramientas, mapa para pintar, brújula de límites y un arcade de adivinanzas.

## Otras materias

- Informática: computadora, hardware, software, mouse, teclado, carpetas, ventanas y atajos.
- Ciencias Naturales: ecosistema marino, biodiversidad, veda, componentes bióticos y abióticos, calor, temperatura y energía solar.

## Publicar en Vercel

1. En Vercel, selecciona **Add New → Project**.
2. Importa este repositorio de GitHub.
3. Framework Preset: **Other**.
4. No hace falta configurar comandos ni variables.
5. Pulsa **Deploy**.

La aplicación usa HTML, CSS y JavaScript puro. También puede abrirse localmente haciendo doble clic en `index.html`.
