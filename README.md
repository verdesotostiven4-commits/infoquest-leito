# InfoQuest Leito · Misión Informática

Juego educativo web para repasar el examen de Informática de 5.º EGB.

## Contenido

- Partes principales de la computadora.
- Mouse, pantalla, CPU y teclado.
- Hardware y software con ejemplos.
- Partes del teclado y del mouse.
- Puntero o cursor.
- Crear una carpeta y encender el equipo.
- Botones minimizar, maximizar/restaurar y cerrar.
- Atajos Ctrl + C, V, X, Z.
- Atajos Windows + E, R, L, D.
- Ruta turbo, misiones, repaso, simulacro y práctica de errores.

## Publicar en Vercel

1. En Vercel, selecciona **Add New → Project**.
2. Importa este repositorio de GitHub.
3. Framework Preset: **Other** (normalmente se detecta automáticamente).
4. No hace falta configurar comandos ni variables.
5. Pulsa **Deploy**.

La aplicación es HTML, CSS y JavaScript puro. También puede abrirse localmente haciendo doble clic en `index.html`.
